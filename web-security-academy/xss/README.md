# Web Security Academy — XSS

実際に挑戦したLabの記録とPoCだけを保存します。

## Labごとの構成

1つのLabにつき1ディレクトリ作ります。

```text
lab-name/
├── README.md
└── solve.py
```

READMEの基本構成:

```markdown
# Lab名

## 正常系の挙動

## Entry Point

## Source

## Transformation

## Sink

## Context

## 重要だった観察

## Exploitの考え方

## Python PoC

## 学んだこと

## 再利用できる知識

## References
```

初回挑戦中は、AIに完成したExploitや解法を書かせないようにします。
