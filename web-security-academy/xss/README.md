# Web Security Academy — XSS

実際に挑戦した Lab の Python PoC を保存します。

## Lab ごとの構成

1つの Lab につき1つの Python ファイルを置きます。ファイルの冒頭に Lab 名、攻撃手順、実行方法をコメントで書き、その下に PoC を実装します。Lab ごとの README は作りません。

毎回共通する部分は [Requests 用の最小テンプレート](../../boilerplates/wsa_requests.py) をコピーして使います。`run()` の通信と成功判定、冒頭の攻撃手順は自分で埋めます。

初回挑戦中は、AI に完成した Exploit や解法を書かせないようにします。
