# Web Security Academy — XSS

実際に挑戦した Lab の記録と PoC だけを保存します。

## Lab ごとの構成

1つの Lab につき1ディレクトリ作ります。

```text
lab-name/
├── README.md
└── solve.py
```

README の基本構成:

```markdown
# Lab名

## 正常系の挙動

## Entry Point

## Source

## Transformation

## Sink

## Context

## 重要だった観察

## Exploit の考え方

## Python PoC

## 学んだこと

## 再利用できる知識

## References
```

初回挑戦中は、AI に完成した Exploit や解法を書かせないようにします。
